# docs/

На сервере сюда кладутся PDF, которые бот отправляет пользователям.
В репозитории их нет, потому что это документы вуза и Студсовета.

| Файл | Что это |
|---|---|
| `FAQ.pdf` | «Часто задаваемые вопросы»; листалка в Mini App собирается командой `nab faq` |
| `Карта корпуса.pdf` | планы этажей, команда `nab map` |
| `1. Устав Финансового университета.pdf` … `9. Положение о Студенческом совете.pdf` | нормативно-правовая база, команда `nab docs` |

Имена файлов НПБ заданы в `config.py` → `NPB_FILES`.
